FAQ

Questions we get on the scoping call.

Do we need Managed Operations Sprint first?
No. EnterpriseFLOW Run is a standalone service for the Agent Fabric layer. If you already have managed operations for your MuleSoft and Informatica footprint from another provider, EF Run covers the Agent Fabric layer separately.
Which agent clouds do you support?
Salesforce Agentforce, AWS Bedrock, Google Vertex AI, and Microsoft Copilot Studio — all discoverable via Agent Scanner, which reached GA in January 2026.
What does Flex Gateway policy management cover?
MCP and A2A protocol policy, OAuth 2.0 and JWT authentication, TLS encryption, rate limiting, and compliance logging against your defined data classification policy.
How do you handle Agent Fabric version upgrades?
Prowess manages Agent Fabric and Anypoint version upgrades within the engagement. Upgrade windows are scheduled monthly with the customer architecture team to avoid disruption to production agents.
